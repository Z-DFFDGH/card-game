# 这个目录 = 角色立绘。你往这里放图。

## 命名规则（最重要）
文件名（不含后缀）必须和 characters.json 里该角色的 "名称" 字段【完全一致】。
程序就是靠文件名去找图的，差一个字、差一个空格都会找不到。

    例：characters.json 里写  "名称": "星野"
        那么图片就必须叫       星野.png   或   星野.jpg

支持的后缀：.png / .jpg / .jpeg

## 关于缺图
找不到对应图片时不会崩，程序会画 assets/images/placeholder.png 顶上。
所以你可以先只放一部分图，或者干脆先不放，游戏照样能跑。

## 关于文件名里的坑字符
空格、大小写、全角半角都算不同字符。
特别注意：文件名开头/结尾【不要有空格或换行符】。
（你原来的 ba/ 目录里就有一个文件名叫 "\n浦和 花子.png"，
 开头藏了一个换行符，肉眼完全看不出来，程序永远匹配不上。
 本目录里的副本已经改成正常的 "浦和 花子.png" 了，但你源目录里那个还在。）
